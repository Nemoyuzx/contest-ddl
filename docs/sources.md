# 数据源与采集边界

## 国内竞赛：赛氪

读取赛氪新版公开赛事页自身调用、无需登录的只读前端 JSON 接口，不调用管理接口，不绕过验证码，不抓取用户数据。每日只请求指定工科分类，并对详情请求限量、限速。处理顺序：

1. 分别请求数学建模、程序设计、机器人、电子自动化、计算机信息技术、机械、大数据和人工智能分类；
2. 按 `contest_url` 去重，排除培训、咨询、留学、考研等推广与 CTF；
3. 清理标题开头的考试倒计时、领证书、热门推荐等营销标签；
4. 只保留当前或未来 500 天内仍有关键节点的工科赛事；
5. 通过赛事详情接口获取报名/比赛起止、主办方、参赛对象、正文、分阶段赛程与公开附件；
6. 正文转换为纯文本，不在本站渲染第三方 HTML；
7. 标记 `needs_official_verification`。

若页面结构变化，适配器失败会显示在 `source-status.json`，旧数据不会被删除。

## 国内竞赛：赛事官网自动核验

使用 `xcg1125/college-competition-ddl` 的 `competitions.json` 作为官网入口目录，按本项目关心的工科类别筛选后，每天并发但限速访问。目录里的 `deadline` 可能过期，因此**只使用 `website`、赛事名称、类别和主办方，不直接导入目录中的日期**。

每个站点最多读取官网首页和两个同域候选通知页，并遵守 `robots.txt`。抽取器只接受日期所在正文里的“报名截止 / 作品提交截止 / 比赛时间”等明确标签，或表格中紧邻日期的短标签；新闻发布日期、更新时间、获奖名单、普通新闻列表和没有标签的孤立日期都会被拒绝。仅保留当前日期前 120 天到后 500 天的时间。被接受的通知页还会保存清洗后的纯文本正文摘要，供网站展开查看。

官网存在 JavaScript 渲染、证书错误、失效链接或正文为 PDF 等情况时，本轮会安全跳过。`data/source-status.json` 的 `official_sites.details` 会记录目录数、筛选数、成功站点、失败原因样本及接受字段，便于后续为重要赛事增加专用适配器。可通过 `OFFICIAL_SITE_LIMIT` 和 `OFFICIAL_SITE_WORKERS` 控制每日站点数与并发数。

## 黑客松

当前稳定来源是 Major League Hacking 官方高校黑客松活动页。适配器读取页面内公开结构化事件数据，保留活动官网、起止时间、形式和地点。平台没有提供报名截止时不会用比赛开始时间伪装成报名截止，网站会明确提示回官网确认。

扩展新平台时必须满足：公开访问、可稳定定位单个活动、至少有明确起止/报名日期、允许限速访问。对返回 403、需要登录或验证码的平台直接降级，不尝试规避。

## 夏令营 / 预推免

使用 CS-BAOYAN 社区维护的 BoardCaster `data.json`，读取当前年与下一年夏令营、当前年预推免；再按计算机、电子、通信、网安、自动化、机械、AI、机器人等院系/描述关键词过滤。每条记录保留原学校通知 URL。

院校标签采用三份可审计快照：教育部公布的 [“985 工程”学校名单](https://www.moe.gov.cn/srcsite/A22/s7065/200612/t20061206_128833.html)、[“211 工程”学校名单](https://www.moe.gov.cn/srcsite/A22/s7065/200512/t20051223_82762.html)，以及教育部 2022 年公布的 [第二轮“双一流”建设高校及建设学科名单](https://www.moe.gov.cn/srcsite/A22/s7065/202202/t20220211_598710.html)。标签彼此独立，一所学校可同时具有三个标签。分类只按学校规范名称和代码中明列的校区/更名别名匹配，不根据字符串包含关系猜测。

## 已停用来源

CTFtime、Hello-CTFtime 与 Codeforces API 已从采集器中移除。管线同时过滤历史缓存和其他来源发现的 CTF 事件，确保它们不会通过生命周期保留机制重新进入 JSON、ICS 或网站。
